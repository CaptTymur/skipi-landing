Какую версию Skipi скачиваете?

Skipi — desktop-приложение для Windows, macOS и Linux. Не веб-версия. Все данные остаются на вашем компьютере.

На какой операционной системе будете запускать?

Skipi — нативное desktop-приложение для всех трёх платформ. Веб-версия не используется.

Загрузка

⚠ Skipi Crewing требует токен авторизации

Crewing-версия — для крюингов, шипменеджеров и фрахтователей. Без токена приложение установится, но при первом запуске попросит вставить токен, и без него интерфейс не разблокируется. Запросите токен заранее — обычно высылаем в течение рабочего дня.
