Мобильное приложение доступно через тестирование

Google Play требует период тестирования перед публичным выпуском. Поэтому пользователь получает мобильную версию так: становится тестировщиком, мы добавляем его Google email, и он устанавливает приложение из Play.

  1. Нажмите «Стать Android-тестировщиком» у нужного продукта.
  2. В письме укажите Google email, под которым вы входите в Google Play.
  3. Мы добавим этот email в список тестировщиков и пришлем ссылку.
  4. На телефоне откройте Play именно под этим аккаунтом и нажмите Join testing / Install.
  5. Если видите «App not available», ответьте на письмо и приложите скриншот.

Windows предупреждения

Beta-сборки могут показывать Windows Defender SmartScreen. Это нормально для ранних установщиков без широкой репутации. Нажмите More info, затем Run anyway. Если корпоративный EDR блокирует файл, напишите на info@skipi.app.

macOS Gatekeeper

Если macOS пишет, что не может проверить приложение, перенесите app в Applications и выполните в Terminal:

xattr -dr com.apple.quarantine "/Applications/Skipi.app"

Для Crewing используйте путь "/Applications/Skipi Crewing.app".

Linux установка

  • DEB: sudo dpkg -i file.deb, затем sudo apt --fix-broken install.
  • AppImage: chmod +x file.AppImage и запуск двойным кликом.
  • Если AppImage просит FUSE: sudo apt install libfuse2.
