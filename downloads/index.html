После установки на macOS: перетащите Skipi.app в папку Applications, затем откройте Терминал (⌘+Space → «Terminal» → Enter) и выполните одну команду:

xattr -dr com.apple.quarantine /Applications/Skipi.app

Это снимает карантинный флаг, который macOS навешивает на любое приложение, скачанное вне App Store. Один раз — и Skipi запустится. Без неё система покажет «Apple не удалось подтвердить, что приложение не содержит вредоносного ПО».

Проверка скачанного файла

Seafarer публикуется через RF-маршрут: Seafarer manifest. Crewing публикуется через отдельный RF-маршрут: Crewing manifest. Для входа в Crewing нужен токен авторизации, его можно запросить на info@tymur.org.

Подпись Windows Authenticode будет включена для будущих публичных релизов. Текущие beta-установщики могут показывать предупреждение "Unknown publisher".
