Skipi needs project funding to keep the maritime AI assistant and its API running.

What this is

Skipi is a live AI assistant for seafarers — purpose-built for shipping, already in production at assistant.skipi.app, with apps around one data layer. Running that assistant takes compute, model and API access, and the work to keep the product moving.

This is project funding, not personal charity. Contributions go toward the assistant, the API, and the product seafarers already use.

How to contribute

Two official channels: PayPal (one-time or recurring) and Patreon (membership). Questions: info@skipi.app.
