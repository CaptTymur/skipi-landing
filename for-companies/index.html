Privacy и trust

Почему сигналам можно доверять

🔒 HMAC-приватность экипажа

Каждый отзыв хранится с server-side HMAC-хешем — связать сигнал с конкретным моряком технически невозможно, даже с admin-правами. Это снимает страх retaliate и делает данные честными. Вы получаете агрегированный профиль, а не идентификаторы.

⚓ Captain-led intelligence

Skipi построен Master Mariner'ом (Captain Tymur Rudov), который сам ходит в море и работает фрахтовым брокером. Каталог из 16 секций отзыва — экспертная интерпретация, а не «опрос с лайками». Та же экспертиза формирует weight'ы composite score.

📊 Per-epoch breakdown

Smut менеджмента, владельца или флага не размывается в усреднении. Skipi показывает разрез по эпохам — видно, как менялось состояние судна со сменой управления. Это критично для банков (covenant trigger) и для брокеров (отказ от старых сигналов post-acquisition).

🛡 Moderation gate

Каждый отзыв проходит pending moderation перед публикацией. Очевидные аномалии (бот-спам, нерелевантные секции, retaliatory rage) отсеиваются. Это не open review platform с лайками — это структурированный signal layer с ручным контролем качества.

Вопросы B2B

Частые вопросы

Как происходит онбординг?

После запроса доступа верифицируем корпоративный домен и роль, выдаём авторизационный токен и проводим короткий онбординг (20–30 минут): показываем интерфейс, объясняем как читать индексы, отвечаем на вопросы по протоколу. Дальше команда работает самостоятельно.

Сколько стоит доступ?

Для ранних enterprise-партнёров tier бесплатный — мы заинтересованы в feedback и validation use case'ов. Прайсинг enterprise-доступа формируется на основе ролевой модели и числа пользователей; конкретные условия согласуем при онбординге.

Как часто обновляется база?

Vessel-база (50k+ судов) обновляется через Equasis / RightShip enrichment и собственный сбор news flow. Отзывы экипажей публикуются после moderation gate (обычно 1–3 дня). Composite score пересчитывается при каждом новом отзыве — без batch delay.

Есть ли API / интеграция?

Сейчас доступ через desktop-клиент Skipi Crewing (Windows / macOS / Linux). Publicly-available API для intelligence-слоя в работе — приоритет диктуется early-adopter запросами. Если у вас критичный use case для интеграции в собственные системы (compliance pipeline, treasury system, vetting workflow) — скажите при онбординге, поднимем в приоритет.

Чем отличается от Equasis и RightShip?

Equasis показывает регистры, инспекции, PSC. RightShip даёт vetting baseline. Skipi показывает то, что видят только те, кто реально был на борту: культуру безопасности, реакцию менеджмента, vetting pressure изнутри, payment reliability, отношение к экипажу. Сигналы комплементарны — Skipi дополняет paper-clean регистры реальным operational signal.
